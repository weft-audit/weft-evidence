# 2026-10-21：单入口意图链实跑记录（脱敏）

> 证据等级：单次实跑记录，不是基准测试，也不能替代复杂任务回归。

## 目的

验证一个自然语言入口能否在保留确认闸的前提下，把工作意图交给目标编译器，
再触发既有工作链。该验证只使用一条简单只读任务，不执行写操作。

## 实际链路

```text
自然语言工作意图
  → 系统要求显式确认
  → 所有者输入“确认执行”
  → 目标编译器返回 READY
  → 多 Agent 工作链
      ├─ 办事者
      ├─ 微小审计
      ├─ 独立审计
      └─ 记忆管家给出待批准写回句
```

任务被明确限定为只读检查，不修改文件，不启停服务。

## 观察结果

- 确认前没有直接进入工作链；
- 确认后目标编译器状态为 `READY`；
- 工作链实际返回办事者、微小审计、独立审计和记忆管家四段输出；
- 独立审计未发现越权写入；
- 记忆管家只给出候选记账句，持久化写入仍等待所有者批准；
- 本次没有把“运行了工作链”扩大解释为“所有功能已经闭环”。

## 证明边界

本次记录能证明：

1. 入口确认闸、目标编译器和既有工作链可以串成一条实际执行路径；
2. 只读任务可以在不自动授予执行权的情况下完成一次回传。

本次记录不能证明：

1. 写操作、权限升级、服务启停和不可逆任务的可靠性；
2. 长任务、并发、模型失败、工具超时和断线恢复；
3. 记忆写回已经自动化——该步骤仍由所有者批准；
4. 任意自然语言意图都能被正确分类或编译。

## 后续验收

下一轮至少补三类反例：明确拒绝、确认后失败并回滚、长上下文触发截断。
只有这些反例也通过，才能扩大“单入口链路可稳定运行”的结论。
