# 案例：账本事件的字段映射缺口与口径待补（2026-10-19）

## 现象（真实日志，脱敏）

桌面端账本已在线并落盘三条事件，但字段解析不完整：

```text
{"ts":"2026-10-18T22:39:30.877Z","session":"session-a17d…",
 "provider":"unknown","model":"unknown","prompt_tokens":0,"completion_tokens":0}
```

## 定性

账本「活着」（事件管道通了），但「口径没通」：provider/model 未解析、
token 为 0。原因方向：桌面端宿主事件形状与账本解析器期望的 usage 字段
不匹配，解析器对缺失字段降级为 unknown/0。

## 处理

- 未粉饰：直接公开残缺日志与缺口说明。
- 已列为待办：给 dsh-ledger 补字段兼容（provider/model/token 映射）。

## 这则案例说明什么

我们公开的不是「完美数据」，是「系统如何诚实地暴露自己的缺口」——
这正是治理层的可观测性证据。
