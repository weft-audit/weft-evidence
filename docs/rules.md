# 规则体系（公开版）

> 方法论公开版：不含任何私人内容。这套纪律是"意图驱动开发"的另一半——
> AI 负责实现，规则负责约束，人类负责终裁。

## 一、施工五道门禁

1. 留退路：改动前必须先能回滚，没退路不许动手。
2. 验世界：核对真实状态，不是命令返回值。
3. 验不了就停：停下报告，不猜着继续。
4. 一次一处：改完验完，再动下一个。
5. 不许掩埋：不为解决 A 把默认切到 B。

## 二、下判断七条检查

读原始材料了吗；能按失败方式拆开吗；它有反馈吗；治病还是埋病；
来源与推断标了吗；是不是同一模式又来一次；给的是清单还是下一步。

## 三、自检三闸

1. 用接口前，先引原文——没贴定义不许写。
2. 说"完成"，必须挂命令+原始输出——没有输出视为没验。
3. 同一处不许猜第二次——一次猜错，第二次读原文；连续两次猜同一处即停。

## 四、查新补漏

动技术决策前必查三类：官方最新发布、所引 issue/bug/限制的当前状态、
有无更新推翻旧依据。查完落查新记录；旧依据被推翻，先停再改。

## 五、DoD 完成否定清单

以下情况一律不算完成：测试被跳过却无说明；验证只写"没问题"没有命令与输出；
改了范围外文件不说明；残留风险无负责人；验收标准未逐条检查。

## 六、防自噬原则

医者不能自医：程序不许修改自己，要修，只能由别的程序来修；能力扩展走插件。
起因：Agent 修改自身代码导致脑死亡的真实事故。

## 七、判断清单（20 条，挂书源）

1. 前提可验：前提是不是事实，追得回可观察的印象吗。（休谟 copy principle）
2. 推理有效：从前提到结论这一步跳没跳。（简单逻辑学 / 论证是一门学问）
3. 样本与基础比率：结论从多大的样本来，同类事通常什么比率。（超预测 / 黑天鹅）
4. 可证伪：什么证据能推翻它，找不出来就是立场不是判断。（对伪心理学说不）
5. 逆向检查：怎么做会必然得到相反结果。（穷查理逆向思维 / 系统之美）
6. 激励与利益：说这话的人被什么激励，谁获益——尺子也量自己。（穷查理 / 策略思维）
7. 叙事与后见：是不是故事讲太顺，把随机说成了必然。（对赌 / 黑天鹅）
8. 锚定与框架：数字和判断是不是被最先出现的数带偏。（思考快与慢）
9. 概率化：能写成几分之几吗，不能就明说不可估。（对赌 / 超预测）
10. 后果与健壮：如果错了代价多大、可逆吗；沉没成本不计入下一步。（穷查理）
11. 承认不知：不确定就标空、标存疑，不替它补全。（论语 2.17）
12. 学思互证：只学不想、只想不学都废。（论语 2.15）
13. 看人三层：先看行为，再看来路，最后看他安心待在哪。（论语 2.10）
14. 系统视角：先问要素、连接、目标，警惕单点归因。（系统之美）
15. 元自检：下完判断补一句"我这看法可能来自哪个偏误"。（清醒思考的艺术）
16. 递归预期：先算"他会怎么想我会怎么想"。（策略思维）
17. 判断专家：先看方法与校准记录，不先看头衔。（超预测）
18. 采样与趋势：多时点采样，别拿单点推断趋势。（穷查理宝典）
19. 引前查更：引用任何数字前，先查它是否已被划掉或更正。（历史的教训）
20. 来源权重：二手纲要不是原文，引用前回原文核对并标出处等级。（超预测）

> 修订通道：用后发现某条不灵 → 附实例提修订 → 裁决 → 批准才改；裁决前旧条
